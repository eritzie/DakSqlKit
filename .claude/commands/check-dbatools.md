# dbatools Check

- https://docs.dbatools.io
- https://dbatools.io/commands
- https://github.com/dataplat/dbatools/search?q=<keyword>

If no cmdlet exists, state explicitly: "No dbatools cmdlet found for [task]" 
then implement using native PowerShell for the gap.
